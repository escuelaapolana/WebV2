Los números salen de la base de datos al abrir la página. Lo que imprimas o descargues sale de aquí.
Cómo guardar un informe en PDF o en Excel

Todos los números salen directos de la base de datos del club en el momento de abrir esta página. Usa «Imprimir / PDF» para guardar un informe en PDF (en el diálogo de impresión, elige «Guardar como PDF») y «Descargar CSV» para abrirlo en Excel.
