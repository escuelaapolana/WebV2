# MAPA DE REDIRECCIONES · web vieja  ->  web nueva
# ==================================================
#
# QUE ES ESTO
# La web vieja (atletismoapolana.com, hecha con Flazio) tiene 129 paginas
# publicadas y mas de 200 entradas de blog. Google lleva anos apuntando a
# esas direcciones. El dia que el dominio empiece a servir la web nueva,
# TODAS esas direcciones dejan de existir: quien llegue desde Google o desde
# un enlace guardado se dara de bruces con un «pagina no encontrada», y el
# club perdera de golpe el posicionamiento que tiene.
#
# La solucion es una REDIRECCION: decirle al navegador y a Google «esto se ha
# mudado, y se ha mudado AQUI». Google traslada entonces la reputacion de la
# pagina vieja a la nueva. Este archivo es la lista de mudanzas.
#
# COMO SE USA
#   python3 herramientas/redirecciones.py            -> genera _redirects
#   python3 herramientas/redirecciones.py --paginas  -> genera paginas puente
# Lee docs/seo-cambio-de-dominio.md antes de tocar nada.
#
# FORMATO: una linea por mudanza,  ruta_vieja  ->  ruta_nueva
# Las lineas que empiezan por # son comentarios.
# Un * al final de la ruta vieja significa «y todo lo que cuelgue de ahi».
#
# Las rutas viejas de esta lista son REALES: salen del sitemap.xml de
# atletismoapolana.com. No hay ninguna inventada.
